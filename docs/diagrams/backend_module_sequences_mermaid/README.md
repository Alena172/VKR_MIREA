# Диаграммы последовательности серверной части в Mermaid

Каталог содержит `Mermaid`-версии актуального основного набора диаграмм из `docs/diagrams/backend_module_sequences`.

Основной набор для отчета:

- `01_identity_module_sequence.mmd` - модуль `identity`: регистрация, вход, JWT и текущий пользователь.
- `02_vocabulary_module_sequence.mmd` - модуль `vocabulary`: перевод, захват слова, фоновое сохранение, общий словарь, SRS и graph-синхронизация.
- `03_training_module_sequence.mmd` - модуль `training`: асинхронная генерация упражнений, использование интересов, проверка ответов и сохранение сессии.
- `04_review_module_sequence.mmd` - модуль `review`: SRS-очередь, отправка результата повторения, план и рекомендации.
- `05_graph_module_sequence.mmd` - модуль `graph`: интересы пользователя, тематические кластеры и тематические подсказки для упражнений.
- `06_ai_module_sequence.mmd` - модуль `ai`: единый фасад перевода, генерации определений и учебных материалов.
- `07_tasks_platform_sequence.mmd` - инфраструктурный слой `tasks`: постановка фоновых задач, привязка владельца и безопасное получение результата.

Эти файлы синхронизированы с `PlantUML`-версией основного комплекта и с текущей структурой серверной части.

Старые `.mmd`-файлы по отдельным детализированным сценариям сохранены только как вспомогательные иллюстрации.
