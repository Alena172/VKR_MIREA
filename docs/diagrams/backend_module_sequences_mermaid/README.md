# Диаграммы последовательности модулей серверной части в Mermaid

Этот каталог содержит `Mermaid`-версии модульных диаграмм верхнего уровня.

Основной набор для отчета:

- `01_identity_module_sequence.mmd`
- `02_vocabulary_module_sequence.mmd`
- `03_learning_module_sequence.mmd`
- `04_learning_graph_module_sequence.mmd`
- `05_ai_services_module_sequence.mmd` как AI-адаптер
- `06_tasks_platform_sequence.mmd`

Они соответствуют той же укрупненной архитектуре, что и `PlantUML`-файлы из каталога `docs/diagrams/backend_module_sequences`: четыре доменных модуля, AI-адаптер и инфраструктура задач.

Старые `.mmd`-файлы по подмодулям и детализированным сценариям сохранены как вспомогательный материал и могут использоваться как приложение.

Дополнительно добавлен компактный сценарий словарного модуля:

- `13_vocabulary_delete_sequence.mmd`
- `14_vocabulary_ai_add_sequence.mmd`
