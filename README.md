# Платформа изучения английского

Это платформа для изучения английского языка русскоязычными пользователями. Проект объединяет:

- серверная часть на FastAPI
- клиентское приложение на React
- браузерное расширение для захвата слов со страниц
- PostgreSQL, Redis, Celery и Flower для хранения данных и фоновых задач

Продукт построен вокруг одного практического цикла:

1. найти слово в живом контексте
2. сохранить его вместе с переводом и определением по контексту
3. потренироваться на сохраненной лексике
4. повторить слабые слова и слова, срок повторения которых уже наступил, через SRS

## Структура репозитория

```text
backend/    серверная часть: FastAPI-модульный монолит, миграции БД, тесты, Celery-задачи
frontend/   клиентское одностраничное приложение на React + Vite
extension/  браузерное расширение на Manifest V3
gateway/    конфигурация Nginx для единой локальной точки входа
docs/       Дополнительные заметки по проекту
```

## Быстрый старт

### Полный запуск через Docker

1. Скопируй файл окружения серверной части:

```bash
cd backend
copy .env.example .env
cd ..
```

2. Подними стек:

```bash
docker compose up -d --build
```

3. Открой сервисы:

- клиентское приложение: `http://localhost:5173`
- API серверной части: `http://localhost:8000`
- единая локальная точка входа: `http://localhost:8080`
- Flower: `http://localhost:5555`

### Режим разработки с автоматической перезагрузкой

```bash
docker compose -f docker-compose.yml -f docker-compose.dev.yml up --build
```

Этот режим включает:

- автоматическая перезагрузка серверной части через uvicorn
- сервер разработки клиентского приложения с отслеживанием изменений
- автоматический запуск миграций при старте серверной части

## Основные возможности продукта

- JWT-аутентификация с входом или регистрацией в один шаг
- персональный словарь с леммой, переводом, исходным предложением и контекстным определением
- захват слов через браузерное расширение
- перевод с английского на русский на основе гибридной локальной и AI-логики
- асинхронная генерация упражнений
- отправка учебных сессий с проверкой ответов и обратной связью
- очередь SRS-повторения, план повторения и сводка прогресса
- семантический профиль для автоматического профиля интересов и различения смыслов многозначных слов

## Текущая модель выбора слов

Основной сценарий выбора слов связан с повторением уже известных слов:

- недавние ошибки
- слова, срок повторения которых наступил по SRS
- семантический профиль помогает объяснять интересы пользователя и смысл слова

В дальнейшем семантический профиль можно использовать для подбора новой лексики из внешнего набора кандидатов.
