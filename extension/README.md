# Браузерное расширение VKR Studying

## Назначение

Расширение добавляет в браузер режим `Studying`.

Когда режим включен:

- пользователь выделяет английское слово или короткую фразу на странице
- расширение отправляет выделение на backend
- рядом с выделенным текстом появляется плавающее окно с переводом
- пользователь может:
  - добавить выделение в словарь
  - закрыть окно

Это быстрый захват новой лексики прямо во время чтения сайтов, статей и документации.

## Как это работает

1. Пользователь открывает popup расширения.
2. Выполняет вход или регистрацию через `email + password`.
3. Включает переключатель `Studying`.
4. На любой странице выделяет английское слово или фразу.
5. Content script:
   - берет выделенный текст
   - пытается извлечь ближайший контекст
   - вызывает `POST /api/v1/translate/me`
6. Рядом с выделением показывается плавающее окно.
7. По кнопке `Добавить в словарь` вызывается `POST /api/v1/vocabulary/me/from-capture`.

## Структура

- [manifest.json](d:/VKR/VKR_V3_Curs/extension/manifest.json)
  Манифест расширения Chrome/Edge на Manifest V3.
- [popup.html](d:/VKR/VKR_V3_Curs/extension/popup.html)
  UI панели расширения: auth + toggle режима.
- [popup.js](d:/VKR/VKR_V3_Curs/extension/popup.js)
  Авторизация, сохранение токена, переключение режима `Studying`.
- [content.js](d:/VKR/VKR_V3_Curs/extension/content.js)
  Логика выделения текста, вызов backend и показ окна рядом с выделением.
- [content.css](d:/VKR/VKR_V3_Curs/extension/content.css)
  Стили всплывающего окна на странице.

## Используемые backend endpoints

- `POST /api/v1/auth/register`
- `POST /api/v1/auth/login`
- `GET /api/v1/auth/me`
- `POST /api/v1/translate/me`
- `POST /api/v1/vocabulary/me/from-capture`

## Установка

1. Откройте `chrome://extensions` или `edge://extensions`.
2. Включите `Developer mode`.
3. Нажмите `Load unpacked`.
4. Выберите папку [extension](d:/VKR/VKR_V3_Curs/extension).

## Требования

- Запущенный backend проекта
- Доступность API по `http://localhost:8000/api/v1`
- Пользовательская учетная запись в системе

## Ограничения текущей версии

- API base сейчас зафиксирован на `http://localhost:8000/api/v1`
- Расширение реагирует только на выделения, похожие на английское слово или короткую английскую фразу
- Перевод показывается только при включенном режиме `Studying`
