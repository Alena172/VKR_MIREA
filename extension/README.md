# Браузерное расширение

## Обзор

Браузерное расширение представляет собой легкий клиент для захвата слов в учебной системе. Его задача - сократить путь от "я увидел незнакомое слово на странице" до "это слово уже находится в моей учебной системе".

Основные возможности:

- читать выделенный текст с активной вкладки
- запрашивать перевод у серверной части
- сохранять захваченное слово или фразу в словарь пользователя

Расширение намеренно остается небольшим и сфокусированным. Основной учебный опыт по-прежнему находится в клиентском приложении.

## Технологии

- расширение Chrome / Edge на Manifest V3
- работа через всплывающее окно
- интеграция с API серверной части по HTTP

## Что умеет сейчас

Сейчас расширение поддерживает два основных сценария:

1. Перевести выделенный текст через API перевода серверной части.
2. Сохранить результат в словарь через словарный сценарий `from-capture`.

То есть это вспомогательный инструмент для захвата новой лексики. Основной интерфейс обучения находится в клиентском приложении.

## Установка

1. Открой `chrome://extensions` или `edge://extensions`.
2. Включи режим разработчика.
3. Нажми `Load unpacked` ("Загрузить распакованное расширение").
4. Выбери папку [extension](d:\VKR\VKR_V3_Curs\extension).

## Требования к запуску

Расширение ожидает локально запущенную серверную часть, сейчас ориентированную на:

- `http://localhost:8000`

Также требуется аутентифицированный пользователь, потому что сохранение слов жестко привязано к пользовательскому контексту.

## Модель аутентификации

Всплывающее окно получает JWT по email пользователя и затем использует этот токен для авторизованных запросов.

Текущее поведение:

- получение токена происходит прямо из сценария всплывающего окна
- токен хранится в хранилище браузерного расширения
- расширение использует `/auth/me`, чтобы при необходимости восстановить текущую пользовательскую сессию

Это практичная схема для разработки, и к ней стоит относиться именно так.

## Используемые маршруты серверной части

Расширение зависит от:

- `POST /api/v1/translate/me`
- `POST /api/v1/vocabulary/me/from-capture`
- `GET /api/v1/auth/me`

Если адрес серверной части изменится, расширение тоже нужно будет обновить. Пока этот адрес ориентирован на среду разработки и недостаточно хорошо параметризован для аккуратного развертывания.

## Роль в продукте

Расширение стоит воспринимать как быстрый инструмент захвата:

- обнаружить слово в живом контексте
- перевести его с учетом контекста
- добавить его в учебную систему

С архитектурной точки зрения расширение работает в основном с модулями `identity` и `vocabulary`.

Тренировка, повторение, история и большая часть сценариев выбора слов остаются задачами веб-приложения.
